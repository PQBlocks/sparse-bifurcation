# Changelog

quantum-inspired classical optimization — not cryptography, no security claim

All notable changes to `pqblocks-sparse-bifurcation` are documented in this file.

## [0.1.0] - 2026-10-30

### Added
- Initial public release of Sparse Discrete Simulated Bifurcation solver.
- Compressed Sparse Row (CSR) Numba-compiled dSB computational kernel.
- Dimod `sample_ising` and `sample_qubo` compatibility.
- Deterministic run receipts with SHA-256 state hashing.
- Comprehensive test suite with 103 unit and property tests.
